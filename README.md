# 22 - パックマン迷路ゲーム

**ビルド日**: 2026-11-03
**カテゴリ**: fun
**slug**: pacman-maze-game

## 概要
Canvas上でパックマン風ゲーム。4方向移動でドットを集めてゴーストを避けるクラシックなアーケードゲーム。

## 機能
- Canvasベースの15×15グリッド迷路
- 矢印キーまたはWASDで操作
- 通常ドット(10点)とパワーペレット(50点)を収集
- 2体のゴースト: パックマン方向へのバイアス追跡
- パワーペレット取得後はゴーストが青くなり、食べると200点
- ライフ3つ、0になるとゲームオーバー
- スコア・ハイスコアをlocalStorageに保存
- 全ドット収集でクリア表示
